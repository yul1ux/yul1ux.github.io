**ပထမဦးဆုံး ဒီစာက Exam Guide တစ်ခုမဟုတ်ပါဘူး။ AWS SAA ကို ဘယ်လိုလေ့လာပြီး ဖြေဆိုခဲ့လဲဆိုတဲ့ ကျွန်တော့်ရဲ့ Personal Experience ကို မျှဝေထားတာပါ။**

## Brief Intro about AWS Certified Solutions Architect – Associate (SAA-C03)

AWS SAA-C03 ဆိုတာက AWSAWS services တွေကို အလွတ်ကျက်ပြီး ဖြေရတဲ့ exam မဟုတ်ပါဘူး။ မေးခွန်းထဲက situation ကိုကြည့်ပြီး ဘယ် services တွေကို ရွေးမလဲ၊ အဲ့ဒီ services တွေကို ဘယ်လိုပေါင်းစပ်ပြီး သင့်တော်တဲ့ solution တစ်ခု တည်ဆောက်မလဲဆိုတာကို စဉ်းစားရတဲ့ **intermediate-level certification** တစ်ခုပါ။

Official exam guide အရ AWS services တွေကို အသုံးပြုပြီး cloud solutions တွေ design လုပ်ဖူးတဲ့သူတွေ၊ ဒါမှမဟုတ် IT ပိုင်းမှာ 1–3 နှစ်လောက် အတွေ့အကြုံရှိသူတွေက ဒီ exam အတွက် ပိုအဆင်ပြေပါတယ်။ Exam fee က $150 ရှိပြီး multiple-choice မေးခွန်း 65 ပုဒ်ကို မိနစ် 130 အတွင်း ဖြေပေးရမှာပါ။

Exam guide အကြောင်း အသေးစိတ်ကိုတော့ [ဒီမှာ](https://aws.amazon.com/certification/certified-solutions-architect-associate/) ဝင်ဖတ်လို့ရပါတယ်။

## ဒါဆို ကျွန်တော်ကရော ဘယ်လိုအောင်ခဲ့လဲ?

ကျွန်တော့်မှာ cloud experience မရှိသလို IT နယ်ပယ်တစ်ခုခုမှာ လက်တွေ့လုပ်ငန်းခွင်အတွေ့အကြုံလည်း မရှိပါဘူး။ ဒါပေမယ့် Programming နဲ့ System Administration ပိုင်းကို foundation လောက် လေ့လာဖူးတော့ အခြေခံသဘောတရားတွေကိုတော့ အများစု နားလည်ထားပါတယ်။ အဲ့ဒါကြောင့် အခက်အခဲအရမ်းမရှိဘဲ လေ့လာနိုင်ခဲ့တာပါ။

IT အခြေခံမရှိဘဲ အစကနေ စလေ့လာမယ့်သူတွေအတွက်တော့ အနည်းငယ်ခက်ခဲနိုင်ပေမယ့် သေချာလေးလေ့လာမယ်ဆိုရင် အေးဆေးကျော်ဖြတ်နိုင်ပါတယ်။

အစကနေ AWS ကို သေချာစချင်သူတွေအတွက် AWS Certified Cloud Practitioner (CLF) ဆိုတဲ့ foundation exam လည်း ရှိပါတယ်။ Exam fee $100 ရှိပေမယ့် AWS ရဲ့ အားသာချက်တစ်ခုဖြစ်တဲ့ “Exam တစ်ခုအောင်တာနဲ့ နောက်တစ်ခုအတွက် 50% discount ရတာ” ဆိုတော့ CLF ကနေစရင်လည်း အရမ်းကောင်းပါတယ်။ AWS CLF အကြောင်း ပိုပီးသိချင်ရင်တော့ [ဒီမှာ](https://aws.amazon.com/certification/certified-cloud-practitioner/) သွားကြည့်လို့ရပါတယ်။

## Learning Style

လေ့လာခဲ့တဲ့ပုံစံကတော့ ပုံမှန်ပါပဲ။ အလုပ်တစ်ဖက်နဲ့မလို့ တစ်နေ့ကို 2–3 နာရီလောက်ပဲ လေ့လာဖြစ်ပါတယ်။ စုစုပေါင်း ၁ လခွဲဝန်းကျင်လောက် ကြာခဲ့ပါတယ်။

Stephane Maarek ရဲ့ သင်ခန်းစာတွေကြည့်တယ်၊ note မှတ်တယ်။ သူ့မှာ hands-on labs တွေပါတာမလို့ အရမ်းအဆင်ပြေပါတယ်။ နားမလည်တဲ့ services တွေဆို ChatGPT ကို မေးတာတို့၊ AWS documentation သွားဖတ်တာတို့ လုပ်ပါတယ်။

AWS မှာ services တွေ အရမ်းများတာမလို့ မတူညီတဲ့ services တွေရဲ့ ခြားနားချက်ကို သေချာခွဲခြားမှတ်သားထားဖို့တော့ လိုပါတယ်။ Service နာမည်နဲ့ features တွေကို သိရုံနဲ့ မလုံလောက်ဘဲ ကိုယ်တိုင် note ထုတ်ပြီး services အချင်းချင်း နှိုင်းယှဉ်ကြည့်တာမျိုး၊ အခြေအနေတစ်ခုမှာ **“ဘယ် solution က cost အသက်သာဆုံး ဒါမှမဟုတ် performance အကောင်းဆုံး ဖြစ်မလဲ”** ဆိုတဲ့ logic တွေကို နားလည်အောင် လေ့လာတာက ပိုပြီးထိရောက်ပါတယ်။

Practice exam မှာတော့ Tutorials Dojo ကို များများလေ့ကျင့်တာ အကောင်းဆုံးပါ။ ဖတ်ရတာလွယ်ပြီး စာမေးပွဲနဲ့လည်း အနီးစပ်ဆုံးလို့ ပြောလို့ရပါတယ်။ အပေါ်မှာပြောခဲ့သလို သူ့ရဲ့ official website မှာ exam mode အမျိုးမျိုးနဲ့ ဖြေလို့ရသလို review mode မှာဆိုလည်း အဖြေတွေနဲ့ပတ်သက်ပြီး သေချာလေးရှင်းပြထားလို့ အရမ်းအဆင်ပြေပါတယ်။

Practice exams တွေက ကိုယ့်ရဲ့ weak points တွေကို သိနိုင်တာမလို့ များများလေ့ကျင့်ဖို့ အကြံပြုချင်ပါတယ်။

## Exam Experience

ပထမဦးဆုံး official exam ဖြေဖူးတာဆိုတော့ ကိုယ့်ဘာသာ practice exams တွေ ဖြေကြည့်ရင်း အဆင်သင့်ဖြစ်မဖြစ် ဆုံးဖြတ်ရတာ တော်တော်တိုင်ပတ်ခဲ့ပါတယ်။

အစက online ကနေ ဖြေဖို့ စိတ်ကူးခဲ့ပေမယ့် စည်းကမ်းချက်တွေများတာမလို့ risk များပါတယ်။ အဲ့ဒါကြောင့် exam schedule လုပ်တဲ့အချိန်မှာ ကျွန်တော်နေတဲ့ မန္တလေးက KMD Test Center ကိုပဲ ရွေးဖြစ်ခဲ့ပါတယ်။

Exam schedule လုပ်တဲ့အချိန်မှာ non-native English speakers တွေအတွက် **ESL +30 MINUTES** ကို request လုပ်လို့ရပါတယ်။ မူလ exam duration က 130 + 30 ဆိုတော့ စုစုပေါင်း မိနစ် 160 ရတာပေါ့။

ကျွန်တော့်တုန်းကတော့ မိနစ် 90 လောက်နဲ့တင် ဖြေတာရော၊ ပြန်စစ်တာရော အကုန်ပြီးသွားပါတယ်။

ကျွန်တော်ဖြေခဲ့တဲ့ မေးခွန်းတွေထဲမှာတော့ အဓိကလိုချင်တဲ့အချက်ကို သိရင် option နှစ်ခုလောက်က လုံးဝမဆိုင်တာမျိုး ထည့်ထားပြီး ကျန်နှစ်ခုထဲက ရွေးရတာမျိုးဖြစ်လို့ လွယ်တယ်လို့ ပြောလို့ရပါတယ်။ ကျွန်တော့်အတွက် လုံးဝ tricky ဖြစ်စေမယ့် မေးခွန်းကတော့ ၄ ခုလောက်ပဲ တွေ့ခဲ့ပါတယ်။

## နိဂုံး

ဒါတွေက ကျွန်တော့်ရဲ့ personal experience ကို မျှဝေတာဖြစ်လို့ ဒီအတိုင်းချည်း ကွက်တိလေ့လာရမယ်လို့ မဆိုလိုပါဘူး။ Course တွေမှာလည်း အခြား instructor တွေရဲ့ course ကောင်းတွေ အများကြီး ရှိပါသေးတယ်။

Stephane Maarek ရဲ့ course က စာမေးပွဲကို အဓိက focus ထားတယ်၊ concepts တွေကို အခြေခံကနေ သေချာမရှင်းပြဘဲ လက်တွေ့ပိုင်း သိပ်မပါဘူးလို့ ခံစားရပြီး မကြိုက်တဲ့သူတွေလည်း ရှိပါတယ်။ ဘယ်ဟာကောင်းတယ်ဆိုတာထက် ကိုယ်နဲ့အဆင်ပြေမယ့် course ကို ရွေးချယ်တာက ပိုအရေးကြီးပါတယ်။

**Certified ဖြစ်သွားရုံနဲ့ ခရီးဆုံးသွားတာတော့ မဟုတ်ပါဘူး။** ထပ်ပြီးလေ့လာရမယ့်အရာတွေ၊ လက်တွေ့လုပ်ရမယ့်အရာတွေ အများကြီးကျန်ပါသေးတယ်။ ကျွန်တော်ကိုယ်တိုင်လည်း လေ့လာနေဆဲဖြစ်ပြီး ကိုယ့်လို beginner တွေအတွက် အတွေ့အကြုံမျှဝေတာဖြစ်လို့ အမှားအယွင်းပါခဲ့ရင် တောင်းပန်ချင်ပါတယ်။ လိုအပ်တာရှိရင်လည်း ဝင်ရောက်ဆွေးနွေး ထောက်ပြနိုင်ပါတယ်ဗျ။

စာကတော့ နည်းနည်းရှည်သွားတာမလို့ ဖတ်ရှုပေးတဲ့သူအားလုံးကို ကျေးဇူးတင်ပါတယ်။

နောက်ဆုံး အကြံပြုချင်တာကတော့ **“မေးခွန်းကို သေချာဖတ်ဖို့”** ပါပဲ။ မေးခွန်းက Security ကို လိုချင်တာလား၊ Performance ကို လိုချင်တာလား၊ Cost ကို ဦးစားပေးတာလားဆိုတာ သေချာနားလည်ရင် အဖြေရွေးရတာ တော်တော်လေး လွယ်သွားပါလိမ့်မယ်။

ဒီစာကနေ တစ်ခုခုအသုံးဝင်သွားမယ်ဆိုရင် ကျွန်တော်ရေးရကျိုးနပ်ပါပြီ။
