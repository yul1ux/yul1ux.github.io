## 📌 Brief Intro about AWS Certified Solutions Architect – Associate (SAA-C03)

AWS SAA-C03 ဆိုတာ AWS services တွေကို အလွတ်ကျက်ပြီး ဖြေရတဲ့ exam မဟုတ်ပါဘူး။ မေးခွန်းထဲက situation ကိုကြည့်ပြီး ဘယ် services တွေကို ရွေးမလဲ၊ အဲ့ဒီ services တွေကို ဘယ်လိုပေါင်းစပ်ပြီး သင့်တော်တဲ့ solution တစ်ခု တည်ဆောက်မလဲဆိုတာကို စဉ်းစားရတဲ့ associate-level certification တစ်ခုပါ။

Official exam guide အရ AWS services တွေကို အသုံးပြုပြီး cloud solutions တွေ design လုပ်ဖူးတဲ့သူတွေက ဒီ exam အတွက် ပိုအဆင်ပြေပါတယ်။

- **Exam Fee:** $150
    
- **Format:** Multiple-choice / Multiple-response မေးခွန်း ၆၅ ပုဒ် (မိနစ် ၁၃၀ အတွင်း ဖြေဆိုရမည်)
    
- **Scoring:** မေးခွန်း ၅၀ ပုဒ်ကိုပဲ အမှတ်ပေးပြီး Passing Score က 720 ပါ။
    

_(Exam guide အကြောင်း အသေးစိတ်ကိုတော့_ [_AWS Official Guide_](https://aws.amazon.com/ "null") _မှာ ဝင်ဖတ်လို့ရပါတယ်)_

## ❓ ဒါဆို ကျွန်တော်ကရော ဘယ်လိုအောင်ခဲ့လဲ?

ကျွန်တော့်မှာ Cloud Experience မရှိသလို IT နယ်ပယ်တစ်ခုခုမှာ လက်တွေ့လုပ်ငန်းခွင် အတွေ့အကြုံလည်း မရှိပါဘူး။ ဒါပေမဲ့ Programming နဲ့ System Administration ပိုင်းကို foundation လောက် လေ့လာဖူးတော့ အခြေခံ သဘောတရားတွေကိုတော့ အများစု နားလည်ထားပါတယ်။ အဲ့ဒါကြောင့် အခက်အခဲ အရမ်းမရှိဘဲ လေ့လာနိုင်ခဲ့တာပါ။

IT အခြေခံမရှိဘဲ အစကနေ စလေ့လာမယ့်သူတွေအတွက်တော့ အနည်းငယ် ခက်ခဲနိုင်ပေမဲ့ သေချာလေး လေ့လာမယ်ဆိုရင် အေးဆေး ကျော်ဖြတ်နိုင်ပါတယ်။

> 💡 **Beginner Tips:** အစကနေ AWS ကို သေချာစချင်သူတွေအတွက် **AWS Certified Cloud Practitioner (CLF)** ဆိုတဲ့ foundation exam လည်း ရှိပါတယ်။ SAA အတွက် မဖြစ်မနေ ဖြေထားဖို့တော့ မလိုပါဘူး။ Exam fee $100 ရှိပေမဲ့ AWS ရဲ့ အားသာချက်တစ်ခုဖြစ်တဲ့ _"Exam တစ်ခုအောင်တာနဲ့ နောက်တစ်ခုအတွက် 50% discount ရတာ"_ ဆိုတော့ CLF ကနေစရင်လည်း အရမ်းကောင်းပါတယ်။ _(AWS CLF အကြောင်း ပိုပြီးသိချင်ရင်တော့_ [_ဒီမှာ_](https://aws.amazon.com/ "null") _သွားကြည့်လို့ရပါတယ်)_

## 🧠 Learning Style & Preparation

လေ့လာခဲ့တဲ့ပုံစံကတော့ ပုံမှန်ပါပဲ။ အလုပ်တစ်ဖက်နဲ့မို့လို့ တစ်နေ့ကို 2–3 နာရီလောက်ပဲ လေ့လာဖြစ်ပါတယ်။ စုစုပေါင်း **၁ လခွဲဝန်းကျင်** လောက် ကြာခဲ့ပါတယ်။

1. **Course & Notes:** Stephane Maarek ရဲ့ သင်ခန်းစာတွေကြည့်တယ်၊ note မှတ်တယ်။ သူ့မှာ hands-on labs တွေပါတာမို့ အရမ်းအဆင်ပြေပါတယ်။ နားမလည်တဲ့ services တွေဆို ChatGPT ကို မေးတာတို့၊ AWS documentation သွားဖတ်တာတို့ လုပ်ပါတယ်။ အချို့ ကိုယ်နဲ့သိပ်မရင်းနှီးပြီး ခက်ခဲတဲ့ topic တွေကို ကျော်ကြည့်ဖြစ်ပါတယ်။ ဥပမာ Security & Encryption ပိုင်းတွေမှာပေါ့။
    
2. **Comparison Logic:** AWS မှာ services တွေ အရမ်းများတာမို့ မတူညီတဲ့ services တွေရဲ့ ခြားနားချက်ကို သေချာခွဲခြားမှတ်သားထားဖို့တော့ လိုပါတယ်။ Service နာမည်နဲ့ features တွေကို သိရုံနဲ့ မလုံလောက်ဘဲ ကိုယ်တိုင် note ထုတ်ပြီး services အချင်းချင်း နှိုင်းယှဉ်ကြည့်တာမျိုး၊ _"ဘယ် solution က cost အသက်သာဆုံး ဒါမှမဟုတ် performance အကောင်းဆုံး ဖြစ်မလဲ"_ ဆိုတဲ့ logic တွေကို နားလည်အောင် လေ့လာတာက ပိုပြီးထိရောက်ပါတယ်။
    
3. **Practice Exams Strategy:** Practice exam မှာတော့ Tutorials Dojo ကို များများလေ့ကျင့်တာ အကောင်းဆုံးပါ။ ဖတ်ရတာလွယ်ပြီး စာမေးပွဲနဲ့လည်း အနီးစပ်ဆုံးလို့ ပြောလို့ရပါတယ်။
    
    - **First Attempt:** TD practice exam စဖြေတော့ review mode set တွေကို တစ်ခုပြီးတစ်ခု ဖြေကြည့်တာ average score 70% လောက် ရခဲ့ပါတယ်။ မှားခဲ့တဲ့ မေးခွန်းတွေ ပြန်ဖတ်ပြီး ကိုယ်လုံးဝမသိလို့ မှားတာဆိုရင် သက်ဆိုင်ရာ topic ကို ပြန်ကြည့်ပြီး ပြန်နွေးပါတယ်။ တစ်ချို့ မေးခွန်းတွေမှာ မေးခွန်းသေချာမဖတ်လို့ မှားတာမျိုး ဖြစ်လို့ နောက်တစ်ခါဖြေရင် သတိထားဖို့ မှတ်ထားပါတယ်။
        
    - **Second Attempt:** နောက်တစ်ကြိမ် ပြန်ဖြေတဲ့အခါမှာတော့ 80–90% လောက်ရပြီး မေးခွန်း structure နဲ့လည်း ပိုရင်းနှီးသွားပါတယ်။
        
    - **Key Takeaway:** Practice exam set တွေကို ဆက်တိုက်ဖြေမနေဘဲ ကိုယ်ဖြေထားတဲ့ set မှာ မှားခဲ့တာတွေကို သေချာ review လုပ်ပြီးမှ နောက်တစ်ခု ဆက်ဖြေဖို့ပါ။ မဟုတ်ရင် မေးခွန်းကို မှတ်မိနေတာလား၊ ကိုယ်တကယ်နားလည်လို့ ဖြေနိုင်တာလားဆိုတာ ရောထွေးသွားတတ်ပါတယ်။
        

## 🎯 Exam Experience

ပထမဦးဆုံး official exam ဖြေဖူးတာဆိုတော့ ကိုယ့်ဘာသာ practice exams တွေ ဖြေကြည့်ရင်း အဆင်သင့်ဖြစ်မဖြစ် ဆုံးဖြတ်ရတာ တော်တော်တိုင်ပတ်ခဲ့ပါတယ်။ အထက်မှာပြောခဲ့တဲ့ practice exams တွေမှာ **90% ဝန်းကျင်** လောက်ရရင် ဖြေလို့ရပြီလို့ သတ်မှတ်ရပါတယ်။ တစ်ယောက်နဲ့တစ်ယောက် မေးခွန်း difficulty မတူနိုင်တာမို့ ကိုယ့်ဘက်က လိုအပ်တာ ပြင်ဆင်ထားရင် အကောင်းဆုံးပါ။

- **Test Center:** အစက online ကနေ ဖြေဖို့ စိတ်ကူးခဲ့ပေမဲ့ စည်းကမ်းချက်တွေများတာမို့ risk များပါတယ်။ အဲ့ဒါကြောင့် exam schedule လုပ်တဲ့အချိန်မှာ မန္တလေးက KMD Test Center ကိုပဲ ရွေးဖြစ်ခဲ့ပါတယ်။
    
- **ESL Accommodations:** Exam schedule လုပ်တဲ့အချိန်မှာ non-native English speakers တွေအတွက် **ESL +30 MINUTES** ကို request လုပ်လို့ရပါတယ်။ မူလ exam duration က 130 + 30 ဆိုတော့ စုစုပေါင်း မိနစ် 160 ရတာပေါ့။
    
- **Time Management & Strategy:** Practice exam များများလေ့ကျင့်ထားတာမို့ မေးခွန်းပုံစံတွေနဲ့ ရင်းနှီးပြီး မေးခွန်းဖတ်ရတာက သိပ်အခက်အခဲ မရှိခဲ့ပါဘူး။ ကိုယ့်အတွက် tricky ဖြစ်မယ့် မေးခွန်းမျိုးဆိုရင် ပြီးမှ review လုပ်ဖို့ flag ထားခဲ့ပါတယ်။ ကျွန်တော့်တုန်းကတော့ မိနစ် 90 လောက်နဲ့တင် ဖြေတာရော၊ ပြန်စစ်တာရော အကုန်ပြီးသွားပါတယ်။
    
- **Exam Difficulty & Score:** ကျွန်တော်ဖြေခဲ့တဲ့ မေးခွန်းအများစုမှာတော့ အဓိကလိုချင်တဲ့အချက်ကို သိရင် option နှစ်ခုလောက်က လုံးဝမဆိုင်တာမျိုး ထည့်ထားပြီး ကျန်နှစ်ခုထဲက ရွေးရတာမျိုးဖြစ်လို့ လွယ်တယ်လို့ ပြောလို့ရပါတယ်။ ကျွန်တော့်အတွက် လုံးဝ tricky ဖြစ်စေမယ့် မေးခွန်းကတော့ ၄ ခုလောက်ပဲ တွေ့ခဲ့ပြီး သိပ်မခက်ခဲဘူးထင်ခဲ့တာတောင် **832 မှတ်** ပဲ ရခဲ့ပါတယ်။
