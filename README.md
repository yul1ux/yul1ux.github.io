# Personal Portfolio

My personal portfolio website, built with Astro.

I started this project from the [Starfolio](https://github.com/linksfy/astro-theme-starfolio) template and modified it to fit my own design, content, and needs.

## Built with

* Astro
* React
* TypeScript
* Tailwind CSS
* Markdown

## Development

```bash
git clone https://github.com/yul1ux/yul1ux.github.io.git
cd yul1ux.github.io
pnpm install
pnpm dev
```

The site will be available at `http://localhost:4321`.

Build for production:

```bash
pnpm build
```
